Step-by-Step: Google Stitch for Coffee Hub                                                                                        
                                                                                                                                    
  Phase 1: Set Up Stitch MCP (one-time, ~10 min)                  
                                                                                                                                    
  1. Run the init wizard in your terminal:                                                                                          
  npx @_davideast/stitch-mcp init                                                                                                   
  1. It handles gcloud auth, OAuth, credentials, and project setup automatically.                                                   
  2. Add to your Claude Code MCP config (if the wizard doesn't do it):                                                              
  {                                                                                                                                 
    "mcpServers": {                                                                                                                 
      "stitch": {                                                                                                                   
        "command": "npx",                                         
        "args": ["-y", "@_davideast/stitch-mcp"]                                                                                    
      }
    }                                                                                                                               
  }                                                               
  2. I can run /update-config to wire this into your settings.json if you want.
  3. Restart Claude Code to load the MCP server.                                                                                    
  
  Phase 2: Extract Your Existing Design System (~5 min)                                                                             
                                                                  
  4. Go to stitch.withgoogle.com and create a new project.                                                                          
  5. Feed it your production URL (https://2manybeans.vercel.app). Stitch can analyze a live site and extract the color palette, type
   scale, and spacing patterns automatically. This becomes your baseline design system.                                             
  6. Export the DESIGN.md. This captures Coffee Hub's current visual identity (your warm coffee tones, card layouts, etc.) in a
  portable markdown file that Claude Code can read.                                                                                 
  7. Drop DESIGN.md in your project root (next to CLAUDE.md). Claude Code will reference it for all UI work going forward.
                                                                                                                                    
  Phase 3: Redesign a Screen in Stitch (~15-30 min)                                                                                 
                                                                                                                                    
  8. Screenshot the tab you want to redesign (e.g., RotationTab, InventoryTab, or a new feature screen).                            
  9. Use Stitch's Redesign mode: Upload your screenshot and prompt something like:
    - "Redesign this coffee inventory screen. Keep the warm palette. Make it feel more premium and less cluttered. Mobile-first     
  layout."                                                                                                                          
    - Or use Voice Canvas to talk through what you want changed in real-time.                                                       
  10. Iterate on the canvas. Stitch generates an editable layout. Tweak colors, spacing, component arrangement until you like it.   
  This is the "vibe designing" part, no code involved.                                                                              
  11. For a new tab/feature: Start fresh in Stitch with a prompt like "Design a coffee brewing timer tab for a specialty coffee app.
   Use this design system:" and reference your DESIGN.md. Generate multiple screens and connect them with interaction hotspots.     
                                                                  
  Phase 4: Build It in Claude Code (~30-60 min)                                                                                     
                                                                  
  12. Pull the design into Claude Code via the MCP server, or export the HTML and drop it in your project.                          
  13. Ask Claude Code to implement it: "Convert this Stitch design into a React component for [TabName], following DESIGN.md and
  matching our existing component patterns."                                                                                        
  14. Invoke /ios-design before touching any layout. Stitch outputs web-first HTML/CSS, so you'll need to layer on:
    - Safe area insets (status bar, home indicator)                                                                                 
    - Touch target sizing (44pt minimum)                                                                                            
    - Capacitor-specific patterns (keyboard handling, haptics)                                                                      
    - Platform-conditional styles from your existing isNative checks                                                                
  15. Deploy with your normal Vercel + Capgo OTA flow.

  - /update-config to wire stitch-mcp into your settings.json
  - /ios-design before any UI implementation (mandatory per your lessons)                                                           
  - /deploy when ready to ship
