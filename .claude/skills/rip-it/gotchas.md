# Gotchas

Known failure patterns from real `/rip-it` runs. Add entries here whenever a run hits something weird — this is the highest-signal content for future runs.

Format for new entries:

```markdown
## <Short title of the failure mode>
**First seen:** <run timestamp or date>
**Symptom:** what went wrong (what the skill or a reviewer did/said)
**Root cause:** why (once understood)
**Workaround:** what to do instead, or what to watch for
```

Keep entries short. Link to the relevant `docs/rip-it-runs/<timestamp>.md` report if a specific run illustrates it.
