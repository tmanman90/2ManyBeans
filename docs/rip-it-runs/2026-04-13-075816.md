## Final /ce:review findings

Cross-phase integration review (codex, after all phase-level reviews passed) caught **three real integration-only bugs** that no single-phase review could have spotted:

- ⚠️ **`OnboardingFlow.dispatch` wrapper persisted stale state.** `stateRef.current` was only refreshed by a passive `useEffect` that fires after React commits, but `saveState` ran inside `queueMicrotask` which fires BEFORE commit. Every user action was saving the PRE-transition state, so `localStorage` was always one step behind the user. A close-and-reopen on R5 would have resumed on R4. **Fixed in 311d655** by computing `nextState` synchronously via `onboardingReducer(stateRef.current, action)` inside the wrapper, updating `stateRef.current` immediately, and saving that exact blob. React's `rawDispatch` still commits the same state through its normal render cycle (the reducer is pure).
- ⚠️ **R5 completion guard required only `tinderCards.length===5`, not `palateChart`.** A corrupt hydrated blob `{step:'r6', tinderCards:[5 items], palateChart:null}` caused R6 to bounce to R5, which then saw `length===5` and tried to bounce back — but `advancingRef` was still latched from the first dispatch, so the second `ADVANCE` was dropped and the user dead-ended on a blank R5 `null` render. **Fixed in 311d655** by requiring both `length===5` AND a truthy `palateChart` in `alreadyComplete`. Corrupt state falls through to the normal card-0 entry and the user can redo the round.
- ⚠️ **`completeOnboarding` dropped top-level `marketingConsent` on existing profiles.** Fresh users' `createProfile` path wrote `marketingConsent` + `marketingConsentDate` to the profile root. But the existing-profile `completeOnboarding` merge only wrote `onboardingComplete`/`onboardingAnswers`/`preferences` — so a replayed user who opted in at R12 would get mirrored to `/emailList` but still see the old value in Settings' email toggle. **Fixed in 311d655** by adding `marketingConsent` + `marketingConsentDate` to the payload when `answers.marketingConsent` is a boolean.
