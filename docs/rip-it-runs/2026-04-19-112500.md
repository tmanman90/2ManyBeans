## Caveat from spec
Safari/WKWebView may render the wordmark dark-brown instead of white if `filter: drop-shadow()` fails on the nested image during PNG capture. If this happens on device, generate a pre-whitened version of the logo (RGB set to #FFFFFF, keep alpha) and drop the `brightness(0) invert(1)` portion of the filter. The drop-shadow filters render reliably.
