## What got built

Fix for a spine advancement bug in the tasting coach chat. The six-step header (Smell → First Sip → Acidity → Sweetness → Body → Finish) was advancing on every user message, so a clarifying question in the smell step pushed "STEP 2 · FIRST SIP" on screen while Ruphus was still asking smell follow-ups. Fix is a model-driven `{{step:KEY}}` marker pattern mirroring the existing `{{term:KEY}}` mechanism: Ruphus emits a marker only when he BEGINS a new step; the client strips it at receive time and drives the spine from a monotonic walk over assistant messages. Clarifying messages now hold position. Legacy in-flight sessions (started before this fix) keep working via a fallback heuristic that cannot regress.
