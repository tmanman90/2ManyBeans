## Goal

Make the bean bag photo physically travel (a continuous shared-element morph, not a fade-in) from the small Rotation shelf card into the full trading card when tapped, and morph back on close — the web-faithful equivalent of SwiftUI matchedGeometryEffect, built with framer-motion layoutId. Visual/animation only; no Firebase or feature changes; dev channel only.

## Definition of Done

Tapping a shelf card morphs the bag continuously shelf->card and back on close, using transform/opacity only; the scrim fades independently; reduced-motion disables the morph; flip, note rail, pull-to-dismiss, stat-sheet scroll, peak badge and bag float all still work; `npx vite build` exits 0 and the shelf+detail Playwright harness renders both states with zero console errors and frame-capture shows the bag rect interpolating (not jumping); codex review is clean against the rubric; and Tal signs off on device that it looks and feels right.

## Verification Criteria (the independent gates)

- `v1-build` (programmatic): run `["npx", "vite", "build", "--logLevel", "error"]`, expect `exit_zero`
- `v2-harness` (programmatic): run `["node", "scripts/verify-morph.mjs"]`, expect `exit_zero`
- `v3-review` (judge via codex): Adversarially verify the morph diff. FAIL if: any non-transform/opacity property animates during the morph (width/height/top/left/backdrop-filter/blur => R2 fail); the scrim participates in the FLIP instead of its own AnimatePresence (R4); the bag float or a FitText useLayoutEffect can run mid-FLIP and cause a jump (R8); existing behavior regresses — flip to stat sheet, note rail, pull-to-dismiss front+back, stat-sheet scroll, peak badge (R5); the reduced-motion gate is missing or wrong (R6); or the diff touches Firebase reads/writes, the bean data model, any feature behavior, other tabs, or onboarding (R9). PASS only when the morph is layoutId-driven, transform/opacity-only, scrim-independent, regression-free, and scope-clean.
- `v4-human` (human): On the dev app (device), tap a shelf card and confirm the bag visibly TRAVELS from the shelf card into the trading card (no fade/teleport), the close reverses gracefully, and there is no mid-morph jump or jank — proving R1, R3, R5(feel), R8 as experienced.
