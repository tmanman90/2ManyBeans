## Goal

Execute the seven self-contained animation plans in plans/ (repo root) as one coordinated run on a fresh branch: SettingsPage sheet presentation, scan-save arrival, success-feedback wiring, card press feedback, Ruphus slide-up exit, Quick Recipe menu pop-in, and ScanSheet step transitions. Claude Fable 5 orchestrates ONLY (preflight, spawning, diff review, builds, commits, README statuses, ship, final review) and never writes or edits source code. Every implementation edit is made by a Codex subagent (GPT-5.6 Sol, effort high), one fresh agent per unit, serial order U1..U9.

## Definition of Done

All seven plans landed as their own commits on the fresh branch, every edit authored by a codex:codex-rescue task run with the pinned GPT-5.6 Sol model at effort high (never any other model or effort), every unit diff verified within its source plan's Boundaries by Fable, npm run build green at HEAD, wip-baseline and plans/ commits at the branch root, plans/README.md statuses updated with no TODO remaining, /ship-dev completed with the -devapp bundle label reported and the risk-ordered device checklist delivered to Tal. Terminal acceptance beyond the loop: Tal's on-device sign-off.

## Verification Criteria (the independent gates)

- `v1-build` (programmatic): run `["npm", "run", "build"]`, expect `exit_zero`
- `v2-branch-structure` (programmatic): run `["bash", "-lc", "git log --oneline | grep -q 'wip(pre-existing-baseline)' && git ls-tree -r HEAD --name-only | grep -q '^plans/README.md'"]`, expect `exit_zero`
- `v3-codex-provenance` (judge via fable): Every source-code edit in every unit commit traces to a codex:codex-rescue task whose forwarded flags were exactly --model <U1-pinned GPT-5.6 Sol identifier> --effort high --write --wait. FAIL and re-run the unit if any task ran with a different model, a different effort, or defaulted either flag; silent fallback to another model is a contract violation, not a recoverable warning. FAIL if Fable itself authored any source edit (orchestrator-only rule): the only files Fable may write are plans/README.md, docs/loops/**, and commit metadata. Worst case to catch: a Codex CLI that rejects the model string and silently runs its default model.
- `v4-diff-boundaries` (judge via fable): Per unit: the diff touches only the Files listed in that unit's source plan; every Boundaries bullet holds (no new dependencies; no drag-to-dismiss on the Settings grabber; data-settings-page preserved; scale 0.985 only on cards; no AnimatePresence between ScanSheet steps; cascade only when isNewBean; no haptics on error paths; tasting wizard untouched); the plan's verbatim excerpts are the drift authority, not the ec777a5 stamp; a Codex STOP-on-drift report halts the unit and is surfaced, never improvised around. Worst case to catch: an edit bleeding into the pre-existing wip-baseline hunks in SettingsPage.jsx or TastingTab.jsx — revert and re-task fresh.
- `v5-readme-status` (programmatic): run `["bash", "-lc", "! grep -qE '\\|[[:space:]]*TODO[[:space:]]*\\|' plans/README.md"]`, expect `exit_zero`
- `v6-device-signoff` (human): Tal confirms on his iPhone (dev-channel bundle from /ship-dev, label reported in Settings OTA line) the risk-ordered checklist: Settings sheet visible after 5 consecutive opens (R1, the WKWebView gate); Ruphus close with iOS Reduce Motion ON dismisses within ~300ms (R5 timeout fallback); Ruphus exit symmetry (R5); haptics on scan-save (R2), tasting save, bag finish, star taps, paywall sandbox (R3); new-bean cascade (R2); Quick Recipe menu pop-in (R6); ScanSheet steps (R7); card presses (R4); Reduce Motion pass across remaining surfaces. This is the terminal gate proving R12.
