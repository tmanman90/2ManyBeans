## Goal

Turn the Chat tab into "Professor Ruphus's study": the mascot present on his messages, editorial bubbles (solid user bubbles, no gradient), a characterful "Ruphus is thinking" indicator, tappable starter prompts, and a refined scanned-bean result card. ## Definition of Done

The Chat header has no "AI Chat" eyebrow-over-H1 and no gradient rule (clean Fraunces title + subtitle); assistant messages render with the Ruphus mascot avatar + an editorial bubble while user bubbles are solid (no gradient); the typing indicator is a characterful "Ruphus is thinking" treatment (mascot + calm transform/opacity motion), not bare 3 dots; the intro starter prompts are real tappable buttons that send their prompt; a scanned bean renders as a refined editorial result card with Brew / Guided Tasting / Save preserved; the send button is solid (no gradient) with a haptic on send and the camera + photo strip intact; motion is transform/opacity-only and reduced-motion gated with scroll/auto-scroll preserved; gold is scarce with no gradient/glow/accentSoft structural chrome; every feature works (text, photo analysis up to 3, streaming, message caps, scan routing, Aiden/HandBrew modals, chat context, Pro/paywall gate, iOS keyboard + safe-area); no AI/data/Firebase/ keyboard logic is touched; `npx vite build` exits 0; the Chat Playwright harness shows no header eyebrow/gradient-rule, an assistant Ruphus avatar, solid user bubble + solid send button, tappable starter buttons, the characterful thinking indicator on a loading state, reduced-motion without error, and zero console errors; verify-archive/verify-inventory/verify-morph still PASS; codex review is clean against the rubric; and Tal signs off on device that the Chat feels like Professor Ruphus's study and the keyboard/photo/scan flows still work.
