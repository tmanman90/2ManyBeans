## Definition of Done

The AxisSlider expected marker is a lucide Bone icon at the predicted spot that does NOT show before or while the user sets a value on that slider; the first Next press after a slider answer commits the blind guess, reveals the bone on the same page (opacity-only, reduced-motion instant), ignores rapid second taps, then auto-advances after about a second. The intro copy reframes to "set yours first, then I'll show where I'd land". Ruphus's reaction is a chat thread: the coaching bubble is shown, and the moment the user commits an answer a separate loading bubble appears IMMEDIATELY below it (loader visibility NOT gated on the call debounce), then when the reaction resolves it replaces the loader and the coaching bubble fades out; it reacts to the current step's named input, is pro-gated, and the deterministic core works with AI off (no thread/loader when nothing is loading). The loader is a frosted-glass pill (static -webkit-backdrop-filter + inset rim sheen, never animated, never mix-blend) containing a canvas dot-matrix scanning shimmer (DPR-capped, offscreen-paused, reduced-motion single static frame, role=status); no SVG goo/feDisplacement filter ships. An exited in-progress tasting can be resumed: the draft (answers, step index, phase) survives the wizard closing and tab navigation, and persists in-session in memory (NO Firebase, NO new persisted field); tapping ✕ with real progress shows a confirm, and the guided-tasting entry offers Resume when a draft exists; manual entry still works. All new motion is transform/opacity/canvas-only, reduced-motion-gated, WKWebView-safe, one-accent, design-bank clean. `npx vite build` exits 0; the wizard harness proves bone hidden before touch, still hidden after touch, then revealed by one Next before timed auto-advance, the chat-thread + immediate loader, the canvas loader present, and resume restoring the draft after tab unmount/remount; verify-tasting/inventory/archive/morph/chat still pass; audit + codex are clean; real fresh device screenshots exist for every changed element (bone hidden, bone revealed, dot-matrix loader, chat-thread, resume prompt); and Tal signs off on device.
