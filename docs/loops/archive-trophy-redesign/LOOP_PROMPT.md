## Goal

Keep the Archive's structure (Unforgettable Cups hero strip on top, year-grouped timeline below) but 100x the craft to anti-slop / Apple-caliber and wire tap → trading-card hero morph. Kill the 8 audited slop tells (header glow orb, eyebrow-over-H1, gradient accent rule, Sparkles icon, accent-soft pill spam, twee voice, big-number stat banner, flat decorative timeline rail). Reuse BeanDetailCard + the manual-FLIP morph; add Restore/Delete to the card back and port ownership + saved brew profile so no feature is lost. Visual/UX only; no Firebase or feature changes; dev only.

## Definition of Done

The Archive masthead has no glow orb / no gradient rule / no eyebrow-over-H1 / no twee title and a single tabular-nums stat line; the Unforgettable Cups (5★) strip stays on top as a restrained trophy-card carousel with no Sparkles icon, horizontally scrollable; the year-grouped timeline stays below with neutral surfaces, hairline grouping, tabular-nums counts, and preserved expand-details; tapping any finished bean (cup card or row) morphs the bag into BeanDetailCard (bag flies, no teleport); the card back exposes Restore (→ SEALED) and Delete (destructive, confirmed) plus Learn and Edit-photo, and renders ownership (days owned / finished) + saved brew profile when present; search and every filter (year, min-rating, roaster, origin, process, sort) still filter both the cups strip and the timeline; the three distinct empty states remain; reduced-motion disables the morph; accent (gold) is scarce (5★ + one active state); `npx vite build` exits 0; the Archive Playwright harness renders multi-year finished mock beans with the cups strip scrollable, the timeline year-grouped + chronological, a working tap→morph, search/filter reducing visible beans, no header glow, no Sparkles, reduced-motion with no flight, and zero console errors; verify-inventory and verify-morph still PASS (no BeanDetailCard regression); codex review is clean against the rubric; and Tal signs off on device that the Archive now feels Apple-caliber, not slop.

## Verification Criteria (the independent gates)

- `v1-build` (programmatic): run `["npx", "vite", "build", "--logLevel", "error"]`, expect `exit_zero`
- `v2-harness` (programmatic): run `["node", "scripts/verify-archive.mjs"]`, expect `exit_zero`
- `v3-regression` (programmatic): run `["node", "scripts/verify-inventory.mjs"]`, expect `exit_zero`
- `v4-review` (judge via codex): Adversarially review the Archive-redesign diff. FAIL if any of the 8 audited slop tells survive: a header radial-glow orb, an eyebrow tracked-label directly above an oversized H1, a gradient accent underline/rule, a Sparkles (or decorative Lucide) icon in the cups header, accent-soft gold fills used for structural chrome (accent must be scarce — 5★ + at most one active state, ≤10% of surface), twee copy ("the Archive"/"a record of every cup"/"end of the trail"/"nothing in this corner"), a competing big-number stat banner, or a flat decorative accent-dot timeline rail (R1, R2, R3). FAIL if the Unforgettable Cups strip is not kept on top + horizontally scrollable (R2), or the timeline is not year-grouped + chronological with tabular-nums counts and preserved expand-details (R3). FAIL if tapping a bean does not open BeanDetailCard via the morph or the morph is not transform/opacity-only (R4, R9). FAIL if Restore (→ SEALED) or Delete (destructive + confirmed) is missing/unreachable on the card, or Learn / Edit-photo regressed (R5). FAIL if ownership (days owned / finished) or a saved brew profile (Aiden / hand-brew) that ArchiveDetailSheet showed is lost (R6). FAIL if search or any filter (year, min-rating, roaster, origin, process, sort) regressed or stops filtering the cups strip + timeline (R7). FAIL if the three distinct empty states (first-run, filtered-empty, no-5★ cups) are not all present (R8). FAIL if reduced-motion does not disable the morph (R9). FAIL if BeanDetailCard changes are not additive/prop-gated (Rotation / Inventory regress), or the diff touches Firebase reads/writes, the bean data model, statuses, restore/delete logic, other tabs' behavior, or onboarding (R10). Also FAIL on design-bank violations: more than one accent, heavy/glow shadows, non-hairline structural dividers, missing tabular-nums on counts, or motion >300ms / not ease-out. PASS only when all 8 slop tells are gone, the structure + every feature are preserved, the morph is reused cleanly, and the diff is scope- and design-clean.
- `v5-human` (human): On the dev app (device): open Archive and confirm the masthead, Unforgettable Cups strip, and timeline now read as Apple-caliber (no glow/slop); tap a 5★ cup and a timeline bean and confirm each flies open via the morph; on the card back use Restore and confirm Delete is reachable + confirmed, and that ownership + any saved brew profile show; run a search and a filter and confirm both the cups strip and timeline respond — proving R1, R2, R3, R4, R5, R6, R7 and the overall feel.
