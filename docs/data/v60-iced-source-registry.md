# Iced V60 02 source registry

Executable truth is `src/data/v60IcedSourceRegistry.js` (`v60-iced-sources-v1`). Direct-to-server flash brew is independent from hot V60 selection.

| Family | Canonical starting source | App boundary |
|---|---|---|
| Classic 60/40 | James Hoffmann, 65g/L total | Larger dose/two-serving extraction budget |
| Pulse 67/33 | Partners, Kurasu, Counter Culture | Single-cup dose range; each cadence remains source-specific |

Initial brew ice is post-extraction bypass water, not guaranteed melted dilution. Serving ice is excluded from recipe-water ratios. Slow ice-percolation, removable chambers, flat-bed recipes, and external chillers are explicit exclusions.
