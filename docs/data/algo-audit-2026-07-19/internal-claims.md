## 6. Technique

| Claim | Scope | Source | Confidence |
|---|---|---|---|
| Change ONE variable at a time when dialing in a new bean — never adjust two parameters between brews | All brew methods, dial-in process | AR1 (@caffeineletter) AND ATLAS independently | community-consensus (cross-corroborated: social post + reference book agree) |
| Universal troubleshooting: sour/thin/tea-like = under-extracted → grind finer, raise temp, increase bloom time. Bitter/ashy/harsh = over-extracted → grind coarser, lower temp, shorten inter-pulse time / reduce agitation | All brew methods | AR1 AND ATLAS independently (identical rule stated twice) | community-consensus (cross-corroborated) |
| Grind size is the single biggest lever and should always be adjusted FIRST when taste is off, before temp/ratio/technique | All brew methods | AR1 AND ATLAS independently | community-consensus (cross-corroborated) |
| Fellow's official dial-in method: start coarse, grind progressively finer each brew until astringency appears, then back off exactly one click | Aiden/Opus, official method | AR1 | stated-as-measured (official Fellow guidance) |
| Expect 3-5 brews to fully dial in a new/unfamiliar bean | Aiden, real-world anecdote | AR1 (r/FellowProducts) | single-voice |
| Agitation and grind size trade off inversely: more swirl/agitation allows a coarser grind for the same extraction; less agitation requires finer grind | Pour-over / V60 | ODE, ATLAS (Hoffmann) | community-consensus |
| Hoffmann 1-cup V60 swirl technique: aim for 5g/sec pour rate; total brew time target ~3 minutes for a good grinder | V60, single cup | KAL (Hoffmann transcript) | single-voice |
| Agitation generally increases extraction: French press — stir the crust once at 4 minutes, then leave alone (don't over-stir); pour-over — gentle swirl after pouring to knock loose grounds off the walls; vacuum pot — gentle stir at 30s only, too much stirring causes uneven extraction | Cross-method | ATLAS | stated-as-measured |
| Batch size changes grind + pulse strategy on Aiden: single serve (0-3 cups) grind finer; small batch (3-5 cups) medium; large batch (5-10 cups) grind coarser, with fewer/more-spaced pulses to avoid overflow | Aiden | AR1 | community-consensus (Fellow guidance) |
