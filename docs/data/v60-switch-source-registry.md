## Structural summary (not a citation row — synthesis for U2)

Three genuinely distinct published Switch structures exist, and the plan's default only reproduces one of them:

1. **Percolation-first hybrid (Kasuya)** — valve starts **open**, closes for a brief-to-moderate immersion window, reopens to drain. Two generations exist: the original God/Devil (280g, close 1:15/open 1:45) and the evolved Super Hybrid v2 (300g, closed bloom first, then open-close-open at 2:10/2:55).
2. **Immersion-first (Hoffmann)** — valve starts **closed** through bloom and the full pour, opens only near the end to drain. Genuinely different phase order from Kasuya's; must not be conflated with it (R12).
3. **Long-closed-bloom-then-drip (Kaldi's)** — valve closed only for an extended bloom, then opens and behaves like a slow-drip percolation brew with maintenance pours; no second close event.

Coffee Chronicler's structure (open pour 1 → close pour 2/steep → open drain) is a fourth, hybrid-of-hybrids shape closest to R3's owner-preferred default: it shares Kasuya's open-first ordering but uses a single temperature and a fuller steep window (0:45-2:00, ~75s) rather than Kasuya's brief 30s top-up window. The methodology brief's roast preset table blends Kasuya's temperature-drop signature onto Chronicler's steep-forward timing shape at the medium-roast point; every borrowed number is cited to its source row above, and every blended/interpolated value is labeled as such.
